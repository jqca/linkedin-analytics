🔵 LinkedIn 投稿フロー（Make で自動化済み）
1
核心主張を確認する このアプリ
「💡 核心主張」メニューから投稿のベースとなる考え方・メッセージを確認する。
2
記事を作成・スケジュール設定 このアプリ
「✍️ 記事管理」→「新規作成」から LinkedIn 用記事（約500文字）を作成。
投稿予定日を設定してステータスを「予定」にする。
3
「📤 LinkedIn投稿」ボタンを押す このアプリ
投稿予定日に「✍️ 記事管理」→「📅 スケジュール」タブを開き、対象記事の「📤 LinkedIn投稿」をクリック。
本文を確認・編集して「LinkedIn に投稿して投稿済みにする」ボタンを押す。
4
Make → LinkedIn に自動投稿 Make 自動
アプリが Make の Webhook を呼び出し、Make が LinkedIn に自動で投稿する。
※ Make のシナリオが「ON」になっている必要があります。
5
ステータスが「投稿済み」に自動更新 自動
投稿ボタンを押した時点でアプリのステータスが自動的に「✅ 投稿済み」に変わる。手動操作は不要。
💡 Make 連携のポイント
Make のシナリオが「ON」になっていることを確認してから投稿ボタンを押してください。
投稿の成否は Make のダッシュボード →「Scenarios」→「History」で確認できます。

📝 note 記事投稿フロー
1
noteバリアントを開く このアプリ
「✍️ 記事管理」→「note」タブ → 対象記事の「📝 note」ボタンをクリック。
2
AI で記事を2,000文字に拡張 このアプリ
「🤖 AIで2,000文字に自動拡張」ボタンを押す。
30〜90秒ほどで2,000文字以上の note 用記事が自動生成される。
3
内容を確認して保存 このアプリ
生成された内容を確認・修正し「💾 保存」を押す。
4
note.com に貼り付けて投稿 note
本文をコピー → note.com を開く →「✏️ 書く」→「テキスト」→ タイトルと本文を貼り付け →「投稿する」。
※ ## 見出しは note のエディタで自動的に見出しスタイルになります。
5
URLと公開済みステータスを記録 このアプリ
note の公開 URL をコピーし、アプリのバリアント編集画面の「公開URL」欄に貼り付け。
ステータスを「✅ 公開済み」に変更して保存。
💡 note 投稿のポイント
LinkedIn 投稿の2〜3日後に note に展開すると、同じ内容でも新鮮に読まれやすくなります。
note は SEO に強いため、タイトルにキーワードを入れると検索流入が期待できます。
📘 Zenn 記事投稿フロー（GitHub 経由で完全自動化済み）
1
Zennバリアントを開く このアプリ
「✍️ 記事管理」→「📘 Zenn」タブ → 対象記事の「＋ 作成」または「編集」をクリック。
2
AI で記事をZenn向けに2,000文字に拡張 このアプリ
「🤖 AIで2,000文字に自動拡張（Zenn向け）」ボタンを押す。
エンジニア・技術者向けに再構成された2,000文字以上の記事が自動生成される。
3
内容を確認して保存 このアプリ
生成された内容を確認・修正し「💾 保存」を押す。
4
「📘 Zenn投稿」ボタンをクリック このアプリ
Zennタブの記事一覧から「📘 Zenn投稿」をクリック。
タイトル・絵文字・トピックを確認して「GitHubにコミット → Zennに自動投稿」を押す。
5
GitHub → Zenn に自動公開 Zenn 自動
アプリが GitHub API 経由で articles/ に Markdown ファイルをコミット。Zenn が自動で記事を公開する。
6
Zenn URL がバリアントに自動記録 自動
投稿ボタンを押した時点で Zenn の URL が自動的にバリアントに保存される。手動操作は不要。
💡 Zenn 投稿のポイント
LinkedIn 投稿の2〜3日後に Zenn に展開するとエンジニア層への認知を広げられます。
トピックに quantum / ai / startup を指定すると関連読者に届きやすくなります。
投稿結果は Zenn ダッシュボード → または GitHub リポジトリ → で確認できます。
